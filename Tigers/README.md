# Tigers Baseball Analytics

This project analyzes pitch-level data with Python.

## Pitcher Analysis

- Clean and order pitch and pickoff events
- Calculate pitcher and pitch-type results
- Review pitch speed, spin, movement, release, approach angle, and location
- Compare results against left-handed and right-handed batters
- Review two-strike pitches and first-pitch plans

## Batter Analysis

- Calculate plate appearances, pitches per plate appearance, OBP, SLG, strikeout rate, walk rate, and hit rate
- Review two-strike and early-count results
- Create a summary for batters with at least five plate appearances

## Files

- `Hsu,Bosan_Tigers.ipynb`: data cleaning, analysis, and dashboard code
- `Pitcher_Dashboard.html`: pitcher dashboard
- `AnalyticsQuestionnairePitchData.csv`: source pitch data
- `clean_pitch_data.csv`: cleaned pitch data
- `batters_summary.csv`: batter summary
- `batters_PA5_summary.csv`: summary for batters with at least five plate appearances
- `Hsu,Bosan_Main_Response.pdf`: written response
