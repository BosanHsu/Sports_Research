# Athlete Lab

R practice work using baseball and TrackMan data.

## R Basics

- Import, filter, join, group, and save data
- Create new fields and summary tables
- Work with `dplyr`, `data.table`, and related R packages

Files: `Athlete_Lab_Practice_BasicR.R` and Module 2 to Module 3.2 problem sets.

## Charts

- Plot pitch location and strike zones with `ggplot2`
- Chart pitch speed by pitch type
- Calculate and plot fastball speed and spin percentiles

Files: `Athlete_Lab_Practice_Visuals.R` and Module 4.1 to Module 4.2 problem sets.

## Shiny Apps

- Filter data by team, pitcher, date, pitch type, and batter side
- Show percentile charts, pitch speed charts, strike-zone plots, and data tables

Files: `Athlete_Lab_Practice_App.R`, `Athlete_Lab_Practice_App2.R`, and Module 5.1 to Module 5.3 problem sets.

## Data

- `TestTrackMan.csv`: pitch-level TrackMan data
- `PitcherData.csv`: selected pitcher and pitch data
- `TM_Percentiles.csv` and `Fastball_TM_Percentiles.csv`: pitch speed and spin summaries
