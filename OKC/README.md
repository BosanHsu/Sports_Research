# NBA Schedule Analysis

This project studies NBA schedules with Python.

## Work Included

- Count 4-game-in-6-night stretches
- Compare schedule load by team and season
- Test the gap between team schedule results with a permutation test
- Calculate Brooklyn's defensive effective field goal percentage
- Study rest days, back-to-back games, home and road runs, travel distance, and time-zone changes
- Model the link between schedule factors and team wins
- Build a calendar dashboard for the 2024-25 OKC and Denver schedules

## Files

- `schedule_project_Bosan.ipynb`: code, analysis, charts, and written answers
- `schedule_project_Bosan.html`: HTML export of the notebook
- `Bosan_schedule_dashboard.html`: interactive schedule dashboard
- `schedule.csv`: NBA schedule data from 2014-15 through 2023-24
- `schedule_24_partial.csv`: partial 2024-25 schedule data
- `team_game_data.csv`: team game statistics
- `locations.csv`: team location and time-zone data
- `data_dictionary.txt`: field definitions
