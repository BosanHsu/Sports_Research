# Batter Performance Analytics

This Python project studies batted-ball speed and vertical angle.

## Analysis

- Clean and review batted-ball data
- Compare two measurement methods
- Use bootstrap samples to study player results
- Fit linear regression, random forest, and neural network models
- Predict batted-ball speed from vertical angle
- Review batter and pitcher performance

## Files

- `Bosan_Baseball_Batter_Project.ipynb`: code and analysis
- `Rays_Project_Bosan.pdf`: project report

The notebook reads `battedBallData.csv`. That source file is not included in this folder.
