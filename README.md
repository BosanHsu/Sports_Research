# Sports Research

This repository contains sports analytics projects built with Python and R.

## Baseball

- [Batter Performance Analytics](Batter%20Performance%20Analytics,%20Tampa%20Rays%E2%80%99%20R&D%20Intern%20Candidate%20Baseball%20Analytics%20Project/): batted-ball analysis and player performance models
- [Fantasy Baseball Draft](Fantasy%20Baseball%20Draft%20-%20Reinforcement%20Learning%20for%20Optimal%20Team%20Selection/): fantasy draft simulation with reinforcement learning
- [Tigers](Tigers/): pitcher and batter analysis with an HTML dashboard
- [Athlete Lab](Athelete%20Lab/): R exercises, TrackMan analysis, charts, and Shiny apps

## Basketball

- [OKC](OKC/): NBA schedule analysis, charts, modeling, and a schedule dashboard
